# CareBridge React Web Application

The web application serves administrators, teachers, and parents.

Recommended initialization:

```bash
npm create vite@latest . -- --template react-ts
npm install
```

Add routing, server-state management, forms, validation, Tailwind CSS, component tests, and browser end-to-end tests after the base project is generated.

Follow the feature structure in [PROJECT_STRUCTURE.md](../PROJECT_STRUCTURE.md). The application must consume the Laravel API and must not connect directly to PostgreSQL.
