# CareBridge Laravel Backend

This directory will contain the Laravel REST API. PHP and Composer are required to generate the application.

From the repository root, initialize Laravel into a temporary directory, then move the generated project contents into `backend/` without overwriting this architecture documentation. Alternatively, create the Laravel project before cloning this repository and copy the repository files into it.

Required packages and capabilities:

- Laravel Sanctum
- PostgreSQL driver
- OpenAPI/Swagger generation
- PHPUnit or Pest
- Static analysis and code formatting

Backend implementation must follow [PROJECT_STRUCTURE.md](../PROJECT_STRUCTURE.md) and [API Conventions](../docs/API_CONVENTIONS.md).
