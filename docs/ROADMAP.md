# CareBridge Roadmap

| Weeks | Phase | Main output |
| --- | --- | --- |
| 1-2 | Planning and design | Requirements, user flows, wireframes, ER diagram, API conventions, and ownership |
| 3-4 | Foundation | Repository, environments, Laravel, PostgreSQL, React, Flutter, and CI |
| 5-6 | Identity and academic setup | Authentication, roles, students, guardians, classes, subjects, and assignments |
| 7-8 | Attendance | Entry, correction, summaries, authorization, and tests |
| 9-10 | Results and publication | Marks, comments, report states, approval, publication, and printable report |
| 11-12 | Flutter parent app | Secure login, child view, attendance, results, comments, and history |
| 13-14 | Integration and quality | End-to-end, security, accessibility, performance, and defect correction |
| 15-16 | Deployment and demonstration | Backup/restore, sample data, guides, final report, and presentation |
